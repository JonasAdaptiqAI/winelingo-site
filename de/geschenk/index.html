Fragen

Verfällt der Geschenkcode?

Nein. Er gilt, bis er eingelöst wird, und kann also bis zum Geburtstag oder bis Weihnachten warten.

Wie wird er eingelöst?

Auf winelingo.app/redeem: anmelden oder ein kostenloses Konto erstellen und den Code eingeben. Damit wird der ganze Kurs für dieses Konto freigeschaltet.

Funktioniert er in der iPhone-App?

Ja. Es ist dasselbe Konto: alle Lektionen mit unbegrenzten Herzen, im Web und in der App. Das Scannen von Etiketten in der App ist nicht enthalten.

Ist das ein Abo?

Nein. Es ist eine einmalige Zahlung von 39,99 $, angezeigt in deiner Währung inklusive Mehrwertsteuer. Es verlängert sich nichts automatisch.

In welchen Sprachen?

Deutsch, Englisch, Dänisch und Spanisch. Die Sprache lässt sich jederzeit wechseln.

Kann ich das Geld zurückbekommen?

Ja, innerhalb von 14 Tagen nach dem Kauf, solange der Code nicht eingelöst wurde. Ein erstatteter Code funktioniert nicht mehr.

Ist es schon zu spät für Weihnachten?

Nein. Der Code kommt, sobald du bezahlst, und eignet sich deshalb auch als Last-Minute-Geschenk.
