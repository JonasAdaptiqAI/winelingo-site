No. It works until it is redeemed, so it can wait for the birthday or Christmas.

How do they redeem it?

At winelingo.app/redeem: they sign in or create a free account and type the code. The whole course opens on that account.

Does it work in the iPhone app?

Yes. It is the same account: every lesson with unlimited hearts, on the web and in the app. Label scanning in the app is not included.

No. It is one payment of $39.99, shown in your currency with VAT included. Nothing renews.

Which languages?

English, Danish, Spanish and German. They can switch at any time.

Can I get a refund?

Yes, within 14 days of buying, as long as the code has not been redeemed. A refunded code stops working.

Is it too late for Christmas?

Never. The code arrives the moment you pay, so it works as a last-minute gift too.
